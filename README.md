# SSO App Backend

## Getting Started

This is a simple Node.js application for implementing Single Sign-On (SSO) using SAML. Follow the steps below to run the app locally.

### Prerequisites

- Node.js installed on your machine
- MongoDB running locally or a MongoDB URI
- A `.env` file with the necessary environment variables

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/yourusername/sso-app-backend.git
   cd sso-app-backend

2. **Install dependencies:**

   ```bash
   npm install
   
3. **Set up environment variables:**

   ```bash
   PORT=
   DASHBOARD_URL=
   MONGODB_URL=
   JWT_SECRET=

4. **Run the application:**

   ```bash
   npm run start:dev
